## 🚀 Getting Started — Run It Yourself!

Want to run this locally? It's pretty straightforward, I promise! 😊

### 🛠️ What You'll Need First

- ✅ [Node.js](https://nodejs.org/) — version **18 or higher**
- ✅ **npm** — comes bundled with Node.js, you're all set

### 📦 Step-by-Step Setup

```bash
# 🔽 Step 1 — Grab the code
git clone https://github.com/imVaibhavPal/Personal---Portfolio-.git

# 📂 Step 2 — Jump into the project folder
cd "My Portfolio"

# 📦 Step 3 — Install all the goodies
npm install
```

### ▶️ Fire It Up Locally

```bash
npm run dev
```

🎉 Then open **[http://localhost:5173](http://localhost:5173)** in your browser and enjoy the show!

### 🏗️ Ready to Ship? Build for Production

```bash
npm run build
```

> Your production-ready files will land inside the `dist/` folder — all optimized and ready to deploy!
